This project is about Data Cleaning and Exploratory Data Analysis (EDA) using MySQL. I started by setting up a database and importing the raw dataset, which had 2362 rows. Then, I created a copy of the table to keep the original data safe. After that, I worked on removing duplicate records by assigning row numbers using a CTE and deleting the extra rows. Once duplicates were removed, I standardized the data by trimming spaces in the company column, correcting values in the industry and country columns, and converting the date column from text to a proper date format. Next, I handled null and blank values by replacing blanks with nulls and filling missing industry data based on similar company and location information. I also deleted rows where important columns like total_laid_off and percentage_laid_off were null, and dropped unnecessary columns like the temporary row number. After cleaning, the dataset had 1995 rows. Then, I performed EDA to answer queries like finding maximum and minimum layoffs, calculating total layoffs by company, and analyzing layoffs by month and year. Through this project, I learned practical MySQL skills like using CTEs, handling null values, standardizing data, and maintaining clean datasets for analysis.
